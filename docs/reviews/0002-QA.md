## Checked and correct (qa-agent)
- Amended R2 limit on differences: asset A (1e12, growth 1.0) projects 5.12e14 at 9 years;
  [set_account A kind liability growth_rate 0.7137] keeps each side below 1e15 (hypothetical's own
  `project` -5.13e14) but the difference is -1.02e15, and it errors with `project`'s text; growth
  0.70 gives -9.68e14 and is allowed. In today's money with inflation -0.5 at 9 years, the flip
  also errors on the difference alone.
- Extreme inflation (-0.999999, -0.9, 0.999999, 1e-300, -1e-300) at 1 and 50 years: `what_if`
  errors or succeeds exactly when `project` does. At 0.999999 over 50 years every value deflates
  to 0.00, the flows list is empty and no -0.0 appears.
- Hostile changes give a "change N:" tool error, never an internal error: amounts 1e12+1, 10**400,
  "NaN", true; non-text and nested names; op null, object, upper case or padded; a change that is a
  list or null; changes given as an object or a string; unknown keys (including `horizon_years`
  and `changes` inside a change). Accepted and applied as the tools would: 1e-320, 100,000-char
  names, names with NUL and zero-width characters, start_date 1900-01-01 and 9999-12-31.
- Differential check (R1, R4): 1,500 random lists of 1 to 4 changes (seed 20261009) from the shared
  robustness pools: 1,312 errors identical to "change N: " plus the tool's own error when applied
  one by one; 111 successes whose hypothetical rows and end balances equal `project` after the
  tools ran; 77 skipped (the unknown-key precedence accepted at the Task 0002-T2 review, or both
  sides refusing); 0 mismatches.
- R7 chains that matched R7: swapping two account names through a temporary name; A -> B -> C -> A
  with case variants; rename away then create the old name (a new entry); remove, rename onto,
  rename away, re-create (resumes); create, remove, create (one entry); create then remove
  (dropped); the same name for an account and a flow; padded and mixed-case names; 5,000 remove and
  re-add pairs (flows list empty, 0.19 s).
- Error order: options, then change-list shape, then model path and file, then baseline with no
  accounts, then change values, then hypothetical with no accounts, then the limit. Checked on
  not-JSON, version 2, non-UTF-8, unknown-key, mode 000, directory and relative-path models, an
  empty model and a missing file, against [], an unknown op, a non-object change, an unknown key,
  remove_flow Yacht and a valid create. Matches `project` and the waived P1 and N1. The file was
  byte- and mtime-identical every time; a missing file was never created.
