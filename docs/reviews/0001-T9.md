- Seams: all of AC29 to AC31 through the in-process MCP client session against a temp model
  file (Plan 0001, Test layout: tests/test_0001_model_file.py). AC29 and AC31 are split into
  several `test_ACn_` tests, as confirmed at the Task 0001-T7 merge.
- Red first: AC29 unknown key, AC29 repeated key, AC30, AC31 tilde, AC31 relative path, AC31
  directory modes each failed before their code. AC31 empty value already passed (the old
  `if configured:` treated "" as unset); it was seen red by mutating the check to
  `is None`, then restored.
- Repeated keys are collected by an `object_pairs_hook` and reported after the version check,
  so a file with another version still reports its version, not its shape. The first repeated
  key is named; the message does not say which object holds it.
- Unknown keys are checked against fixed key sets for the top level, accounts and flows (the
  keys the writer emits). The message names the key and "the top level", "an account" or "a
  flow", not which account or flow.
- Relative path: `resolve_model_path` raises `ModelFileError` naming `WHATIF_MODEL_PATH` after
  `~` expansion; every tool resolves the path inside its handler, so every tool fails with it.
  `Path.expanduser` also expands `~user`; R1 names only a leading `~`.
- Symlink: save resolves the path (`Path.resolve`) and writes the temp file beside the target,
  then replaces the target; `model_path` shown to the user stays the configured path.
- Directories: each missing ancestor is created top-down with mode 0700 (pathlib creates parents
  with the default mode, so `mkdir(parents=True, mode=...)` would not do). Existing directories
  are not changed. The test sets umask 022 so the old 0755 behavior is observable.
- No seam questions. Nothing in the spec disagrees with the code.
- Rework (regeneration 1): (1) only a leading `~` or `~/` is expanded (`_expand_home`), so
  `~user/...` stays relative and is refused naming `WHATIF_MODEL_PATH`;
  `test_R1_tilde_with_a_user_name_is_refused_as_relative` was seen red first (on this machine
  `~nobody` expanded to /var/empty and `show_model` succeeded). (2) AC29 tests assert the quoted

  passes against the existing sets, so it was not red. (4) `container` renamed `location` in
  `_check_keys`; the fixture is `umask_022`. Task 0001-T10 had not merged; the task gate ran.
